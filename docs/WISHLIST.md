# WISHLIST.md
VAL — Feature Intake Log

Purpose:
Record client feature requests without committing to delivery timeline.

---

## Rules

1. All requests logged.
2. No feature promised verbally.
3. Tagged as:
   - Adjacent to roadmap
   - Requires architectural change
   - Requires new infrastructure
   - Cosmetic only
4. Reviewed at end of each sprint.
5. Only added to roadmap after technical feasibility review.
