# KAREN CLIENT-ZERO MVP — TARGET 2026-05-25

## Mission

Build a rough but functional Val0 MVP specifically for Karen as client zero.

Target date:
2026-05-25

Price target:
$30/month friends-and-family beta, if useful enough.

## Primary value

Karen wants Val as a family/legal-admin copilot for a land acquisition/trámite familiar.

Val does not act as a lawyer.
Val acts as:
- timeline memory
- event recorder
- task tracker
- document/photo/audio logger
- question organizer
- next-step assistant

## Core MVP scope

1. Land/family case timeline
2. Past/present/future event capture
3. Ask by year/person/topic
4. Simple reminders
5. Basic document/photo/audio attachment logging
6. Tester feedback / idea capture
7. Human profile summary / context-sensitive help
8. Careful privacy/boundary language

## Secondary scope if time allows

- Health/life reminder profile
- Monthly hard injection reminder
- Grocery/supermarket list memory
- Habit/checklist support

## Do not chase before May 25

- full legal analysis
- perfect OCR
- full Word ingestion
- autonomous external messaging
- web monitoring
- public launch polish
- large UI/dashboard

## Product promise

Rough but useful.

Karen can tell Val what happened, what needs to happen, and what documents/photos belong to the case.

Val helps her remember, organize, and decide the next step.
