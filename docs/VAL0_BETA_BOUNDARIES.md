# VAL0 BETA BOUNDARIES

## Safe promise
Val0 helps organize reminders, notes, priorities, simple agenda checks, and feedback loops through Telegram.

## Do not promise
- perfect memory
- full autonomy
- legal/medical/financial certainty
- no bugs
- instant replies every time
- replacement for a human assistant
- complete app polish
- enterprise-level reliability

## Required framing
This is a guided founder beta.

Users should know:
- bugs may happen
- feedback is expected
- features are still being shaped
- support is direct and manual during beta

## Good demo language
"Esto ya sirve para probar casos reales, pero todavía estamos puliendo la experiencia."

## Bad demo language
"Esto lo hace todo."
"Nunca se equivoca."
"Ya reemplaza a una asistente."
