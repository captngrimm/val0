# VAL0 FOUNDER BETA BOUNDARIES V2

## Purpose

This document defines how to explain Val0 honestly to early friends/family testers.

Val0 is useful, but still raw.

## What Val0 is today

Val0 is a Telegram-based founder beta assistant.

It can help a user:
- create an operating profile
- explain their work/life/business
- dump messy updates naturally
- extract structured memory
- recover recent context
- decide a next step
- draft practical follow-up messages
- capture workflow ideas for future roadmap review

## What Val0 is not yet

Val0 is not:
- a finished app
- a full ChatGPT replacement
- a perfect memory system
- a private encrypted consumer product
- a full CRM
- an autonomous employee
- a tool that sends messages externally without user action
- a system that can browse the web automatically unless a web/search tool is explicitly built

## Privacy boundary

Early testers should understand:

- Telegram is the interface, so Telegram handles the messages sent there.
- Val0 stores user data on our server/database.
- Some messages may be sent to AI providers for classification/reply generation.
- Val0 stores raw logs and structured memory to make recall and operator behavior possible.
- Do not paste highly sensitive legal, medical, financial, or private documents unless explicitly comfortable with beta storage.
- Exact document retrieval requires document storage/cold storage, not just fuzzy memory.

## Memory boundary

Val0 has layered memory:

1. Raw logs
   - useful for audit/recovery

2. Structured Exocortex items
   - useful for summaries, whatnow, patterns, workflows

3. Operating profile
   - useful for personalization and recommendations

4. Flow requests
   - useful for roadmap ideas

5. Cold document storage
   - not built yet

## Honest phrase for testers

Val0 is raw, but the point is simple:

You can tell Val what is happening in your life or work, and she starts sorting it into useful memory and next steps.

## Demo-safe promise

Safe:
"Val can help you organize your chaos and remember useful structure."

Unsafe:
"Val remembers everything perfectly."
"Val is fully private."
"Val can run your business automatically."
"Val can browse the web for you right now."
"Val can contact people for you."

## Current test offer

Founder beta means:
- limited users
- guided setup
- rough edges expected
- feedback matters
- useful workflows first
- no fake promises

## Tester feedback questions

Ask after demo:

1. Did this feel useful or just interesting?
2. What would you actually send Val tomorrow?
3. What felt confusing?
4. What felt fake?
5. What would make this worth $30/month to you?
6. What would make you stop using it?
