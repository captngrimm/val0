# VAL0 FIRST-USER SETUP CHECKLIST

## Before demo
- Confirm bot is running
- Confirm /help works
- Confirm /status works
- Confirm /reminders works
- Confirm /bug works
- Confirm /feedback works
- Confirm /idea works
- Confirm guided demo script is ready

## Demo flow
1. Start with simple greeting
2. Show reminder creation
3. Show /reminders
4. Show note capture
5. Show "¿Qué tengo mañana?"
6. Show /bug or /feedback
7. Explain founder-beta boundaries
8. Ask if they want to join for $30/month

## After demo
- Capture user decision
- Capture objections
- Capture confusing moments
- If accepted, document setup status
- If declined, document reason
