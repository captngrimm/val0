# Val0 — checklist de prueba alpha

Pídele al usuario que pruebe esto:

1. Conversación normal
   Que le hable como hablaría normalmente.

2. Continuidad
   Después de unos mensajes:

* “¿Qué estábamos haciendo?”
* “Sigue.”
* “Convierte eso en 3 pasos.”

3. Recordatorio
   Crear un recordatorio real y verificar que aparece.

4. Agenda / calendario
   Preguntar qué hay mañana o crear un evento simple.

5. Voz
   Mandar una nota de voz y, si aplica, probar el modo voz.

6. Drift / foco
   Intentar desviarla una vez y ver si devuelve el foco.

7. Feedback
   Usar uno de estos:

* `/bug`
* `/feedback`
* `/idea`

Qué queremos observar:

* si ahorra tiempo
* si reduce fricción
* si mantiene el hilo
* si se siente útil
* si se siente viva
* si voz, recordatorios y agenda se comportan bien
* cuál fue el fallo más molesto
