# CLIENT-SETUP-01 Founder-Beta Client Setup Kit V1

Purpose: turn a successful warm founder-beta conversation into a repeatable client setup process.

## 1. Purpose Of The Setup Kit

This kit helps Frank move from "yes, this could help" to a controlled first Val0 setup.

The goal is not to onboard every possible feature. The goal is to identify one workflow, define safe boundaries, run a first week, and learn from real use.

## 2. When To Use It

Use this after:

- a founder demo lands well
- the prospect names a real workflow pain
- they ask "how would this work for me?"
- they say yes to a trial, assessment, or setup

Do not use it when:

- the prospect wants magic AI or full autonomy
- the workflow is high-risk and needs professional review first
- there is no clear first workflow
- the client is not comfortable with founder-beta boundaries

## 3. First Client Conversation Intake Questions

Spanish-first intake:

1. ¿Qué estás manejando por memoria, WhatsApp, notas, screenshots o documentos?
2. ¿Qué se te pierde más: agenda, tareas, documentos, seguimiento, ideas, clientes o recordatorios?
3. ¿Qué repites o revisas demasiadas veces?
4. ¿Qué te gustaría que Val te recordara, resumiera o preparara cada semana?
5. ¿Qué datos sí se pueden guardar?
6. ¿Qué datos Val nunca debe guardar o tocar?
7. Si probamos una sola cosa por una semana, ¿cuál sería la más útil?

## 5. Workflow Scoring Matrix

Score each 1-5.

| Criterion | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Pain level | nice-to-have | annoying | actively stressful |
| Frequency | rare | weekly | daily or recurring |
| Data availability | scattered/unclear | some examples | clear messages/docs/tasks |
| Privacy risk | high/sensitive | moderate | low/manageable |
| Ease of first implementation | custom/unclear | partial fit | current Val can support |
| Willingness to pay | unclear | maybe | explicit value |

Best first workflow:

- high pain
- repeated often
- enough sample data
- low/moderate privacy risk
- easy with current Val0
- clear willingness to pay or strong founder-learning value

## 6. "Pick One Workflow First" Decision Rule

Default rule:

> Pick one workflow first. If that workflow helps in Week 1, expand carefully.

Say:

> No metamos diez cosas. Dame un flujo que te quite cabeza y lo hacemos útil primero.

Reject first workflows that require:

- full autonomy
- professional conclusions
- complex integrations
- bulk migration
- team permissions
- high-risk legal/medical/accounting judgment

## 7. Founder-Beta Setup Paths

These are founder-beta/proposed, not final public pricing.

### $30/month Personal Founder Beta

Use for:

- one person/family
- simple personal/admin workflow
- light setup and feedback
- low support burden

### $150 Setup / Assessment

Use for:

- workflow mapping before setup
- multiple possible workflows
- unclear scope or risk
- business/professional prospect not ready for monthly implementation

### $300/month Implementation / Operator Support

Use for:

- serious workflow implementation
- business/admin/document-heavy use
- hands-on setup and refinement
- weekly or biweekly review

## 8. First-Week Implementation Plan

### Day 0 Intake

- confirm first workflow
- define success criterion
- identify sample phrases/data
- define privacy boundaries
- choose setup path

### Day 1 Setup

- create client profile plan
- configure language/tone/workflow assumptions
- prepare initial test phrases
- document what Val may and may not touch

### Day 2 Test

- run controlled phrases
- capture route failures
- verify no overpromises
- keep only top 3 issues

### Day 3 Feedback

- ask what felt useful/confusing
- tighten wording/workflow
- decide whether scope is still one workflow

### Day 7 Review / Payment Decision

- did it save friction?
- does the workflow deserve another week?
- keep, adjust, expand, or stop
- confirm paid path if continuing

## 11. "If They Say Yes" Next Action

Say:

> Perfecto. Entonces el siguiente paso no es meter todo. Es escoger el primer flujo y definir cómo se ve una primera semana exitosa.

Then do:

1. Fill the post-call summary.
2. Pick setup path.
3. Confirm boundaries.
4. Schedule setup/intake.
5. Prepare first controlled test phrases.

## 12. "If They Hesitate" Follow-Up

Send:

> Cero presión. Val0 tiene más sentido cuando hay un flujo repetido que de verdad te pesa. Si ahora mismo no hay uno claro, lo dejamos ahí. Si después te das cuenta de uno - agenda, tareas, documentos, seguimiento, recordatorios, clientes, admin - lo miramos y vemos si vale la pena probar.

## 13. Boundaries

Keep these visible:

- Val does not replace a lawyer, doctor, accountant, financial advisor, or professional reviewer.
- Val does not promise full autonomy.
- Val stays human-in-the-loop.
- Val starts with one workflow first.
- Sensitive writes/actions require confirmation.
- Founder beta means useful, guided, and improving, not finished public SaaS.
