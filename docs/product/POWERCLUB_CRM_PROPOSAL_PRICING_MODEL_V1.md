# POWERCLUB-CRM-BATTLE-01E - Proposal Pricing Model V1

## Purpose

Give Frank a pricing and packaging structure for discussing a paid PowerClub CRM visibility pilot without promising unlimited changes or a final production CRM.

This is a commercial planning document, not a final quote. Final pricing should be confirmed only after discovery and scope freeze.

## Commercial Framing

```text
This is a paid pilot to prove operational visibility: follow-up control, advisor accountability, branch performance, and recoverable opportunity visibility. It is not a final production CRM, not a full SaaS, and not an unlimited customization engagement.
```

The pilot should be sold as:

- A focused visibility layer.
- A scoped workflow and dashboard build.
- A management operating pilot.
- A way to learn what production should include before overbuilding.

The pilot should not be sold as:

- Full CRM replacement.
- Payment system.
- WhatsApp automation.
- Production SLA platform.
- Unlimited report builder.
- AI employee operating the business.

## Package Structure

### 1. Development / Setup

One-time setup for the agreed pilot scope.

Possible included work:

- Scope freeze and field map.
- Data model for agreed records/statuses/follow-ups.
- Executive dashboard view.
- One selected manager view preset.
- Advisor/operator workflow.
- Basic import/export format if scoped.
- Fake-to-real data mapping.
- Pilot launch configuration.

Suggested setup range:

```text
$1,500-$5,000 depending scope
```

Recommended default:

```text
$2,500 setup
```

### 2. Implementation / Training / Rollout

One-time or short engagement to help PowerClub actually use the pilot.

Possible included work:

- Manager walkthrough.
- Advisor training.
- Pilot rules and operating cadence.
- First-week launch support.
- Feedback capture.
- Scope corrections within agreed boundaries.

Can be bundled into setup for a founder-friendly pilot or priced separately for a larger rollout.

### 3. Monthly Maintenance / Support

Recurring support after pilot launch.

Possible included work:

- Small dashboard adjustments.
- Minor field/status label changes.
- Bug fixes within scoped pilot.
- Training reinforcement.
- Monthly reporting review.
- Change request triage.

Maintenance is not unlimited product development.

## Pricing Tiers

| Tier | Setup / development | Maintenance | Use when | Notes |
| --- | --- | --- | --- | --- |
| Founder-friendly / reduced pilot | $1,500-$2,500 | $300-$500/mo | Small proof, limited branch/process, friendly budget, narrow scope | Keep scope tight. One manager view, limited users, limited reports. |
| Recommended pilot | $2,500 setup | $1,000/mo for 3 months | Best default for serious pilot with training and iteration | Strong balance: enough budget to support implementation without overpromising. |
| Corporate / expanded pilot | $4,000-$5,000+ | $1,200+/mo | Multiple branches, more users, heavier reporting/training expectations | Requires stricter scope freeze and change request rules. |

Recommended default offer:

```text
$2,500 setup + $1,000/month for 3 months
```

This can be adjusted if needed, but avoid dropping below a level that makes implementation support impossible.

## Maintenance Tiers

| Tier | Monthly range | Includes | Does not include |
| --- | --- | --- | --- |
| Basic | $300-$500/mo | Light support, small fixes, minor labels/fields, limited check-ins | New modules, major reports, integrations, heavy training |
| Pro | $750-$1,200/mo | Active pilot support, dashboard tuning, training support, monthly review | Full-time ops, custom automation, SLA, full CRM expansion |
| Expanded / managed | $1,500+/mo | Broader rollout support, heavier reporting cadence, ongoing optimization | Enterprise SLA unless separately contracted |

## What Is Included

Depends on tier, but a scoped pilot can include:

- One agreed pilot branch/process, or a clearly defined multi-branch pilot.
- One primary manager dashboard preset.
- Executive dashboard.
- Advisor workflow.
- Follow-up rules.
- Required fields and statuses.
- Basic training.
- Defined maintenance window and support cadence.
- Change request process.

## What Is Excluded

Unless separately priced:

- Payment integration.
- WhatsApp automation.
- Full SaaS/admin configurability.
- Custom mobile app.
- Unlimited reports.
- Production SLA.
- Real-time integrations.
- Full historical migration.
- Advanced permissions/auth.
- AI autonomy.
- Val PowerClub Copilot as a live production assistant.

## What Costs Extra

Price separately:

- Additional branches beyond pilot scope.
- Additional manager view presets.
- Additional reports/dashboards.
- Data cleanup/migration.
- Backend integrations.
- WhatsApp workflows.
- Payment/reconciliation work.
- Custom mobile app.
- Production authentication/permissions.
- SLA/support guarantees.
- Val PowerClub Copilot implementation.

## When To Use Each Tier

### Founder-Friendly / Reduced Pilot

Use when:

- Relationship matters.
- Scope is tiny and controlled.
- One branch or one process only.
- PowerClub needs proof before budget.

Protect yourself:

- Limit reports.
- Limit users.
- Limit changes.
- No integrations.
- No automation.

### Recommended Pilot

Use when:

- PowerClub is serious.
- Management wants visibility and training.
- Frank needs enough budget to implement responsibly.

Default:

```text
$2,500 setup + $1,000/mo for 3 months
```

### Corporate / Expanded Pilot

Use when:

- Multiple branches are included.
- Many advisors/users are expected.
- Leadership wants more reporting.
- Training and support expectations are higher.

Protect yourself:

- Require signed scope freeze.
- Define change request pricing.
- Price maintenance at Pro or above.

## How To Avoid Undercharging

- Do not include unlimited changes in setup.
- Do not bundle integrations into a pilot price.
- Do not promise WhatsApp or payments as "later included."
- Do not absorb data cleanup/migration silently.
- Do not include unlimited training.
- Do not price maintenance like passive hosting if Frank is expected to operate, train, adjust, and advise.
- Require a three-month maintenance commitment for a serious pilot.
- Separate "build" from "implementation support."

Rule of thumb:

```text
If PowerClub expects operational responsibility, training, reporting cadence, or active iteration, it is not just setup. It needs maintenance/support.
```

## How To Say This To The Client

```text
Para no prometerles algo infinito, yo separaria esto en tres partes: setup/desarrollo del piloto, implementacion y entrenamiento, y mantenimiento mensual. Asi congelamos alcance, lanzamos algo util, y despues ajustamos con orden.
```

```text
Mi recomendacion base seria algo como $2,500 de setup y $1,000 mensuales por tres meses para acompanar el piloto. Si quieren algo mas pequeno, podemos reducir alcance. Si quieren varias sucursales, mas reportes o mas entrenamiento, lo cotizamos como piloto expandido.
```

```text
Lo importante es que WhatsApp, pagos, integraciones, app movil, SLA de produccion y reportes ilimitados no entren escondidos en el piloto. Eso se scopea aparte si despues hace sentido.
```

## Do Not Say

- "Esto incluye cambios ilimitados."
- "WhatsApp lo agregamos rapido sin costo."
- "Pagos tambien van incluidos."
- "Esto ya es un CRM final."
- "Cualquier reporte que pidan entra."
- "El mantenimiento es solo hosting."
- "Val va a operar PowerClub automaticamente."
- "El Copilot ya viene incluido en V1."

## Scope Creep Risks

| Risk | Control |
| --- | --- |
| More branches added mid-pilot | Change request and price adjustment |
| More reports requested | Report limit in scope freeze |
| WhatsApp/payment assumptions | Explicit exclusion |
| Training expands to entire company | Training limit and extra session pricing |
| Data cleanup becomes manual project | Separate data cleanup scope |
| Copilot becomes expected | Future/add-on only unless separately scoped |

## Pilot Success Criteria

A paid pilot is successful if:

- Managers can identify overdue and stuck opportunities.
- Advisors understand their daily follow-up workflow.
- Branch performance is visible.
- Source/channel quality is visible.
- PowerClub can decide what production should include.
- Scope remains controlled.
- The pilot produces a clear go/no-go or expansion decision.
