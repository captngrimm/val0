# POWERCLUB CRM - Karen Alignment Message V1

## Purpose

Give Frank a warm, simple message to send Karen before asking for a boss/GM meeting.

The goal is not to sell the full pilot by text. The goal is to confirm whether the demo feels directionally right and whether Karen thinks it is strong enough to show leadership.

## WhatsApp-Friendly Message

```text
Hola Karen, ya tengo una primera demo/mockup del CRM operativo + dashboard gerencial para PowerClub.

Importante: todavia no es un sistema final ni usa datos reales. Todo lo que se ve es ficticio/sintetico para poder conversar la idea sin tocar informacion real.

La demo esta enfocada en visibilidad gerencial: seguimiento atrasado, responsabilidad por asesor, comparacion por sucursal, oportunidades en riesgo y una ficha rapida por asesor.

Me gustaria que la veas con estos ojos:
1. Si el dolor y el flujo se sienten correctos para PowerClub.
2. Si el dashboard ayuda a explicar el valor a gerencia.
3. Si esto esta suficientemente fuerte para ensenarlo al jefe/gerente general.
4. Que ajustarias antes de llevarlo a esa reunion.

No quiero venderlo como “ya esta listo”; quiero usarlo para validar si el piloto tiene sentido y que alcance deberiamos congelar antes de cotizar formalmente.

Cuando puedas, lo revisamos rapido y me dices que le falta para que sea una conversacion seria con gerencia.
```

## Shorter Version

```text
Hola Karen, ya tengo una primera demo/mockup del CRM + dashboard gerencial de PowerClub.

No usa datos reales; todo es ficticio para validar la idea. La demo muestra seguimiento atrasado, desempeno por asesor, sucursales, oportunidades en riesgo y ficha por asesor.

Me gustaria que me digas si el dolor/flujo se siente correcto, si lo ves fuerte para mostrarlo al jefe/GM, y que ajustarias antes de esa reunion.
```

## What Frank Should Ask Karen Live

- "El dolor que estamos mostrando, seguimiento perdido y poca visibilidad gerencial, se siente correcto?"
- "El dashboard habla en el idioma del jefe o todavia esta muy tecnico?"
- "Que parte mostrarias primero: gerencia, asesores, riesgo, sucursal o precio?"
- "Que palabra, numero o promesa podria sonar peligrosa?"
- "Quien deberia estar en la reunion con el jefe/GM?"
- "Antes de cotizar, que alcance minimo deberiamos congelar?"
