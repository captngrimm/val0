# POWERCLUB CRM - Boss Meeting Prep V1

## Purpose

Help Frank turn the static demo into a controlled leadership conversation with PowerClub.

This is a pilot validation meeting, not a production handoff and not a final quote meeting.

## Meeting Objective

Get leadership aligned on three points:

- The operational pain is real: weak follow-up visibility can create lost opportunities.
- The pilot direction is useful: dashboard-first visibility plus advisor workflow.
- The next step is discovery + scope freeze before a paid pilot proposal.

## Opening Framing

```text
Esto es una demo de piloto, no el sistema final. No usa datos reales de PowerClub y no esta conectado a WhatsApp, pagos ni backend. La usamos para validar si la capa de visibilidad gerencial resuelve un dolor real antes de congelar alcance y cotizar formalmente.
```

## 5-Minute Demo Flow

1. Start in `Vista gerencial`.
2. Point to the fake-data notice.
3. Show `KPIs gerenciales clave`.
4. Click one KPI and show the explainability drawer.
5. Show `KPIs de riesgo y rescate`.
6. Open `Ficha del asesor`.
7. Use one view preset:
   - `Ejecutiva` for leadership summary.
   - `Riesgo` if they care about lost follow-up.
   - `Asesores` if accountability is the main pain.
8. Mention future `Val PowerClub Copilot` only as optional/add-on.
9. End by asking which pilot view matters first.

## 15-Minute Discovery Flow

Use the demo as the visual anchor, then ask:

- Which branch or process should be piloted first?
- How many advisors/operators should enter V1?
- Where is follow-up most often lost today?
- What does management need to see every morning?
- Which statuses do you actually use?
- What counts as "atrasado" in the real operation?
- Which sources/channels matter most?
- Which reports are mandatory and which can wait?
- Who approves scope and budget?
- What is explicitly out of scope for V1?

## Questions To Ask Leadership

- "If you had this dashboard every morning, what decision would you make faster?"
- "Which metric would change behavior immediately?"
- "Which branch or team should be the first pilot?"
- "What would make this pilot successful after 30/60/90 days?"
- "What data export or Excel sample can we review safely after the meeting?"

## What Not To Say

- "This is already connected to PowerClub."
- "This uses real PowerClub data."
- "This is the final production CRM."
- "WhatsApp automation is included."
- "Payment integration is included."
- "Any change is included."
- "Val already operates PowerClub."
- "Val PowerClub Copilot is included in V1."

## How To Explain Fake Data

```text
Los numeros son ficticios. No estamos intentando reportar la realidad de PowerClub hoy. La demo usa datos sinteticos para mostrar el tipo de visibilidad, decisiones y preguntas que el piloto podria habilitar cuando trabajemos con datos reales aprobados.
```

## How To Explain Pricing Without Hard-Quoting Too Soon

```text
No quiero cotizar infinito sin alcance. Lo sano es separar setup/desarrollo, implementacion/training y mantenimiento. Primero congelamos sucursales, usuarios, campos, reportes y exclusiones; despues se aterriza el paquete.
```

Use only ranges if they ask early:

- Reduced/founder-friendly pilot.
- Recommended pilot.
- Corporate/expanded pilot.

Keep the default anchor internal unless the room is ready:

```text
$2,500 setup + $1,000/month for 3 months, adjustable after scope freeze.
```

## How To Position The 3-Month Pilot

```text
La propuesta sana seria un piloto de 3 meses: primero validamos la operacion, luego medimos adopcion y visibilidad, y despues decidimos que entra a una version mas robusta.
```

Success criteria:

- Managers can see follow-up status without asking for manual reports.
- Advisors have a clearer next action.
- Branches can be compared without blaming blindly.
- Overdue/risk cases are visible early.
- Scope does not expand without approval.

## How To Position Val PowerClub Copilot

```text
Val Copilot no es promesa de V1. Es una posible evolucion: cuando existan datos reales aprobados y reglas claras, Val podria ayudar a explicar KPIs, responder preguntas gerenciales, preparar resumenes semanales, sugerir coaching y priorizar riesgos. Siempre como apoyo a gerencia, no como reemplazo de decisiones humanas.
```

- Pilot validation tool, not final production CRM.
- Fake data only until approved real data sources exist.
- No backend/payment/WhatsApp promise.
- No unlimited customization.

- No real implementation before scope freeze.
