# PowerClub CRM Battle Stage - Executive Leave-Behind V1

## Problem

PowerClub may be losing opportunities when follow-up is late, invisible, or dependent on scattered tools, shift memory, manual reports, or files by name.

The issue is not simply "needing a CRM." The issue is management visibility:

- Which advisor followed up?
- Which leads are overdue?
- Which branch is leaking?
- Which channel creates quality opportunities?
- Which opportunities can still be protected today?

## Proposed Pilot

Build a focused CRM visibility pilot that gives managers and advisors a clear operating layer for commercial follow-up.

The pilot starts with fake/demo alignment and then freezes scope before any production implementation.

## V1 Includes

- Executive dashboard with fake-data prototype already demonstrated.
- Advisor activity ranking.
- Advisor result ranking.
- Pending and overdue follow-ups.
- Follow-up aging.
- Branch comparison.
- Source/channel performance.
- Status distribution/funnel.
- Stuck opportunity visibility.
- Manager action prompts.
- Operator/advisor workflow concept with next action, notes, status, and history.
- Role concept: advisor, branch manager, general manager.

## V1 Does Not Include

- Real PowerClub data in the demo.
- Payment integration.
- WhatsApp automation.
- Backend sync.
- Production authentication or permissions.
- Migration of historical records.
- Full CRM replacement.
- Autonomous AI operating the business.

## Dashboard / Visibility Benefits

| Visibility area | Benefit |
| --- | --- |
| Follow-up control | Managers can see what must happen today and what is already late. |
| Advisor accountability | Activity and result rankings support coaching without relying only on anecdotes. |
| Branch comparison | Management can identify whether a branch has a volume, follow-up, or conversion issue. |
| Source/channel performance | Time and budget can move toward channels that create real opportunities. |
| Recovery opportunities | Hot, overdue, or stuck leads become a prioritized rescue list. |

## Manager View Options

### Follow-up Control View

Shows:
Due today, overdue follow-ups, aging, lead temperature, owner advisor.

Helps:
Branch managers and sales supervisors.

Decision:
Who must act today, what should be escalated, and what can be reassigned.

Financial reason:
Fast follow-up protects warm intent before the opportunity cools.

### Advisor Performance View

Shows:
Activity ranking, result ranking, conversion, overdue rate, coaching signals.

Helps:
General manager, branch manager, sales lead.

Decision:
Who needs coaching, who is overloaded, who performs well, and what behavior should be replicated.

Financial reason:
Better advisor execution can improve conversion without buying more leads.

### Branch Comparison View

Shows:
Open opportunities, conversion, overdue follow-ups, risk, estimated value by branch.

Helps:
General manager and regional leadership.

Decision:
Which branch needs management attention, staffing review, or process support.

Financial reason:
Branch-level visibility shows where operational leakage may be costing sales.

### Recovery Opportunities View

Shows:
Hot leads at risk, stuck opportunities, overdue high-value prospects, protected opportunity estimate.

Helps:
Managers responsible for closing current-month opportunities.

Decision:
Which leads to rescue first and where to intervene immediately.

Financial reason:
Prioritizes the opportunities most likely to be protected before they are lost.

## 30 / 60 / 90 Rollout

### First 30 Days

- Discovery meeting.
- Freeze scope.
- Confirm first manager view.
- Confirm fields and statuses.
- Prepare pilot workflow and fake-to-real data map.
- Train a small pilot group.

### 60 Days

- Run pilot with one or two branches or one defined commercial process.
- Review follow-up discipline, advisor usage, manager dashboard value, and friction.
- Adjust fields, labels, and reporting.

### 90 Days

- Decide whether to expand, integrate, or keep as lightweight operational layer.
- Define production requirements only after pilot evidence.
- Decide if Val PowerClub Copilot add-on is worth scoping.
