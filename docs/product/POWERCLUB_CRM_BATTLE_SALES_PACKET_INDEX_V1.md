# POWERCLUB-CRM-BATTLE - Sales Packet Index V1

## Purpose

One command-center index for Frank before, during, and after the PowerClub CRM meeting.

This packet turns the sprint assets into a usable sales path:

```text
demo -> discovery -> scope freeze -> paid pilot proposal
```

This is not runtime config, not a deployment instruction, and not permission to use real PowerClub data.

## Recommended Meeting Order

1. Open with pilot framing.
2. Show static demo first, starting on the executive dashboard.
3. Explain manager visibility and protected opportunity.
4. Show manager view options.
5. Show operator/advisor workflow only after the executive story is clear.
6. Ask discovery questions.
7. Discuss pricing ranges only if the room is ready.
8. Close with discovery meeting, scope freeze, and paid pilot proposal.

## Capability Unlocked

- Frank can show the dashboard first instead of explaining abstractly.
- Frank can explain why each manager metric matters.
- Frank can offer package ranges without improvising.
- Frank can freeze scope before the client asks for everything.
- Frank can position Val PowerClub Copilot as future/add-on without overpromising.
- Frank can describe future AI use cases clearly: KPI explanations, manager questions, weekly summaries, coaching prompts, and risk prioritization after approved real data exists.
- Frank can move from demo to discovery to paid pilot with a clear path.

## Guardrail Reminder

- Fake data only.
- No real PowerClub data in demo materials.
- No backend promise.
- No payment integration.
- No WhatsApp automation.
- No final production CRM promise.
- No unlimited customization.
- Val PowerClub Copilot remains future/add-on only unless separately scoped.
- Val assists management; it does not replace management decisions.
- Real AI use requires approved data sources, reviewed formulas, and scope freeze.
