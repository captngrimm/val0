# POWERCLUB-CRM-BATTLE-01E - Scope Freeze Checklist V1

## Purpose

Freeze the PowerClub CRM pilot scope before pricing, build, implementation, or training begins.

This checklist protects the pilot from becoming an unlimited CRM/custom software engagement.

## Scope Freeze Principle

```text
If it is not listed here, it is not included in V1.
```

The pilot is a scoped visibility layer, not a final production CRM.

## 14. Explicit Exclusions

Not included in V1 unless separately priced:

- Payment integration.
- WhatsApp automation.
- Full SaaS/admin configurability.
- Custom mobile app.
- Unlimited reports.
- Production SLA.
- Backend integrations beyond approved scope.
- Full historical migration.
- Advanced permissions/auth.
- AI autonomy.
- Val PowerClub Copilot implementation.

## 15. Val PowerClub Copilot Boundary

Val PowerClub Copilot is future/add-on only unless separately scoped.

Potential future use:

- Explain dashboard metrics.
- Suggest next management questions.
- Help managers decide what to request or change.
- Summarize pilot feedback.

Not included:

- Full autonomy.
- Live operations.
- Production assistant claims.
- Unapproved PowerClub knowledge ingestion.

## 16. How To Say This To The Client

```text
Para que el piloto salga bien, necesitamos congelar alcance antes de construir. Eso no limita el futuro; evita que el primer piloto se convierta en una lista infinita de cambios y nos permite medir si la visibilidad gerencial realmente ayuda.
```

```text
Todo lo que quede fuera se puede pedir despues como cambio o fase dos. Lo importante es que V1 tenga una promesa clara: seguimiento visible, responsables claros y decisiones gerenciales mejores.
```

## 17. Do Not Say

- "Eso tambien entra."
- "Lo ajustamos ilimitadamente."
- "Luego vemos el alcance."
- "WhatsApp y pagos son faciles, los metemos."
- "No hace falta definir usuarios o sucursales."
- "El dashboard puede tener cualquier reporte."
- "Val Copilot viene incluido."
- "Esto ya es produccion."

## 18. Scope Creep Risk Notes

| Creep signal | Risk | Response |
| --- | --- | --- |
| "Agreguemos otra sucursal" | More users, data, training, reporting | Change request |
| "Necesitamos otro reporte" | Report sprawl | Check report limit |
| "Queremos WhatsApp" | Automation/integration scope | Separate phase |
| "Conectemos pagos" | High-risk integration | Separate phase |
| "Todos los asesores desde dia uno" | Training/support expansion | Expanded tier |
| "Val que responda preguntas automaticamente" | Copilot scope | Future/add-on |

## 19. Pilot Success Criteria

Define success before launch:

- Managers can see overdue follow-ups.
- Advisors use next-action workflow.
- Branch comparison is useful.
- Source/channel quality is visible.
- Stuck opportunities are reviewed weekly.
- Protected opportunity estimate supports action without being treated as real revenue.
- PowerClub can decide expand, adjust, or stop after pilot.
