# FOUNDER_USER_INDIVIDUAL_ROADMAP_TEMPLATE_V0

Purpose:
Reusable operator template for each founder user's individual Val0 Personal roadmap.

This is documentation only. It is not a bot route, not self-serve onboarding, not a runtime profile, and not a promise that every listed capability is enabled. Use it after the founder onboarding conversation to keep the week-1 pilot practical, privacy-aware, and scoped.

Tone:
Spanish-first, operator-ready, practical, privacy-aware, not corporate.

---

## 1. Purpose

Use this template to capture:

- who the founder user is at a high level
- what workflow is being piloted first
- what Val can do now
- what Val should not do yet
- how week-1 success will be judged
- what feedback came from real use
- which ideas are reusable product improvements
- which requests should be scoped separately

Keep this roadmap short enough to maintain after each check-in. Do not turn it into a dump of private facts.

## Operating Principle

The individual roadmap should protect both sides:

- the founder user gets a focused, useful, honest pilot
- Val gets real product learning without absorbing unlimited custom scope

Keep it practical. Keep it consent-aware. Keep it tied to one workflow until the user has proven what is actually useful.
