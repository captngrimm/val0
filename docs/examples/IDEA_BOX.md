# IDEA BOX
_Last updated: 2026-04-12_

Purpose:
This file is the canonical parking lot for non-launch ideas that are worth preserving without letting them derail the current lane.

Rule:
- If an idea is launch-critical, it stays in the active lane.
- If it is not launch-critical, it goes here.
- Every idea must be compressed enough to be recoverable later.
- No idea blob dumping. Capture signal, not chaos.

Required fields for every entry:
- Name
- Status
- Revisit
- What it is
- Why it matters
- Next possible form
- Notes

Status values:
- Priority future feature
- Later
- Maybe
- Dead

Revisit values:
- after April launch
- after reminders/voice
- after calendar hardening
- May review
- TBD

## Watch Instagram with your SOUL

Status: Priority future feature  
Revisit: after April launch

What it is:
Val acts like a shared-attention companion while I consume short-form media. It listens to or ingests reels/videos, summarizes the claims, flags likely bullshit, tells me what needs verification, and can optionally check the strongest claim on the web.

Why it matters:
This is emotionally sticky because it recreates shared media consumption instead of solitary scrolling. It also adds cognitive value by filtering noise, checking truth, and learning operator taste and attention patterns over time. This could become one of the most magnetic differentiators in the whole system.

Next possible form:
Replay copilot MVP:
- audio/transcript in
- claims summary out
- likely true / likely false / unclear classification
- optional web check on strongest claim

Notes:
Longer-term version becomes near-live media copilot mode with personality and shared reaction.


## Intelligent Parking Lot Review

Status: Priority future feature  
Revisit: after April launch

What it is:
Val does not just store parked ideas. She periodically reviews them, groups them by pattern, ranks which ones still look strong, and resurfaces the ones that are becoming strategically relevant.

Why it matters:
A normal parking lot becomes a graveyard. This turns it into a force multiplier. Instead of losing ideas in storage, the system can later say things like: “Boss, you have 3 parked ideas worth revisiting,” or “this old parked idea now matches what we’re building.” That makes memory operational, not decorative.

Next possible form:
Parking lot review MVP:
- retrieve all parked ideas
- group by status and revisit window
- surface top 3 strongest
- flag recurring themes
- show which ones align with the current build stage

Notes:
Longer-term version should proactively resurface ideas at the right time, not only when asked. This is the layer that makes the parking lot feel alive instead of dead storage.
