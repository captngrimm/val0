# Val0 Founder Beta Checklist

## Launch Promise

Val0 is a Telegram-based AI assistant that helps users remember things, save notes, create reminders, track pending tasks, and recover what they were doing — with persistent memory.

## Founder Beta Offer

Price: $30/month  
Format: private founder beta  
Interface: Telegram  
Language: Spanish-first  
Support: direct/manual during beta  

## What Val0 Can Promise Now

- Save notes
- Create reminders
- List reminders
- Create tasks
- List open tasks
- Mark tasks complete
- Show pending dashboard
- Show tomorrow dashboard
- Remember basic facts/preferences
- Show memory dashboard
- Accept bug/feedback/idea reports
- Voice mode with acknowledgement before audio rendering

## What Val0 Should NOT Promise Yet

- Infinite perfect memory
- Full business OS
- Staff/team workflows
- Web dashboard
- Full CRM
- Full automation
- Perfect TTS
- Perfect scheduling
- Legal reliability guarantees

## Required Before First Paid Tester

- Val0 service running
- Fresh-user onboarding tested
- /status tested
- /tasks tested
- /reminders tested
- notes tested
- reminders tested
- task completion tested
- memory dashboard tested
- bug/feedback/idea flow tested
- voice ACK tested
- manual reset/support procedure available

## First Tester Rules

- Start with 3–5 friendly testers
- Spanish-first
- Explain it is beta
- Ask them to report bugs
- Do manual onboarding
- Do not overpromise
- Review logs/checkpoints after each tester
