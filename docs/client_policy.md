## What You Get (Basic Package)

### 1. Conversational Life Copilot
- Large-context conversational assistant
- Distinct personality
- Context-aware replies
- Learns from your interactions over time

### 2. Persistent Memory Engine (PME)
- Important facts stored securely
- Keyword-based recall
- Date-range recall
- Structured long-term memory
- You control what stays or gets deleted

This is not infinite memory.
It is curated, structured, persistent memory.

### 3. Smart Reminder System
- One-time reminders
- Recurring reminders
- Due-date notifications
- Status tracking (pending / completed)
- Escalation capability (future expansion)

### 4. Google Calendar Integration
- Create events
- Read upcoming events
- Basic synchronization layer
- Calendar supplements database (never overrides it)

### 5. Contextual Assistance
- Proactive nudges when relevant
- Memory-based suggestions
- Workflow support
- Friction reduction in daily life tasks

### 6. Voice & Audio
- Voice input supported
- Text-to-speech summaries (standard voice)

## What It Is NOT (Yet)

- No enterprise SLA
- No voice cloning
- No advanced analytics engine
- No automatic legal determinism (unless specified in legal module)
- No guaranteed 24/7 uptime SLA (beta phase)
- No full automated document OCR pipeline (manual ingestion supported)

---

## Privacy Model (Telegram Phase)

- Data encrypted at rest (SQLCipher)
- No human reads conversations
- No analytics resale
- No model training reuse
- Server processes plaintext only during execution

Future (Standalone Phase):
- End-to-end encryption
- Zero-knowledge vault model
- User-controlled encryption keys

Privacy is core to the product.
