# VAL0 FIRST 5-MINUTE DEMO

## Goal
Make Val0 feel useful fast without overpromising.

This is not a stress test.
This is the first impression demo.

## Positioning
Val0 is a Telegram-based personal operator in founder beta.

It helps users:
- remember
- capture notes and ideas
- create reminders
- recover what is pending
- reduce daily mental noise

## Demo rule
Use natural language first.
Use slash commands only when they clearly help.

## 5-minute flow

### 1. Greeting
User:
Hola

Expected:
Valeria replies warmly and invites a simple action.

### 2. Identity
User:
¿Qué eres?

Expected:
Valeria explains:
- she is Valeria
- she works inside Telegram
- she is in founder beta
- she helps remember, organize, capture, and recover daily context
- she does not promise perfect memory or full autonomy

### 3. Capability
User:
¿Qué puedes hacer?

Expected:
Valeria gives useful examples:
- notes
- reminders
- tasks
- ideas
- voice
- recovery

### 4. Note capture
User:
Guarda esta nota: llamar a mamá sobre la cena del viernes

Expected:
Valeria saves the note clearly.

### 5. Reminder
User:
Recuérdame llamar a mamá mañana a las 9

Expected:
Valeria creates the reminder.

### 6. Idea capture
User:
Tengo una idea: Val debería ayudarme a no perder foco

Expected:
Valeria routes it as an idea, not a task.

### 7. Recovery
User:
Estoy perdida, ¿qué hago?

Expected:
Valeria gives a calm reset:
- review pending
- create reminder
- save note/idea

### 8. Tomorrow dashboard
User:
¿Qué tengo mañana?

Expected:
Valeria shows tomorrow’s reminders/tasks.

## Close
Say:

Esto es founder beta.
La promesa no es magia.
La promesa es que Val0 te ayude a recordar, capturar y avanzar con menos fricción.
